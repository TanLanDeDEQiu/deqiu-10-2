## 它长什么样

五个页面：

- **主页** —— 显示余额、最近五条记录，左下角点进总记录页
- **记一笔** —— 金额、备注、收入/支出、可选挂到某个预算上
- **总记录** —— 全部记录，能按时间/只看收入/只看支出三种方式排，能删
- **目标** —— 设一个目标（比如"买电脑 30000，占比 0.3"），显示进度条
- **预算** —— 每月预算，超支会显示，追加预算就是改数字

另外还有：每张卡可以自己选背景图；余额变成负数时，整张卡翻红。

### 目标那个"占比"是怎么算的

一开始想复杂了。最后定成：

```
当前进度 = 余额 × 占比
目标金额 = 目标 ÷ 占比
进度条   = 余额×占比 ÷ (目标÷占比)
```

举例：目标是 30000 的电脑，占比 0.3，那"实际要攒到"是 100000。余额到 30000 时，进度条走 30%。

## 怎么跑

```bash
pip install pywebview pillow
python app.py
```

Python 3.13。数据库用标准库的 `sqlite3`，不需要额外装。

**数据放哪**（`main.py` 里的 `pick_app_dir()`）：

- 程序旁边有 `data\` 目录 → 就用它（便携版，U 盘能带走）
- 没有 `data\` → 用 `%APPDATA%\记账本`（别人电脑上装的版本）

这样同一次打包的 exe，既能当便携版用，也能当安装版用。

---

## 打包

- **PyInstaller** 打成单目录 exe（`--onedir`），把 PyQt5 排掉，省了 80MB
- **Inno Setup** 做安装包（中文界面）

安装包里**只带** `记账本.exe` 和 `_internal\*`，不带数据、不带源码。

## 技术栈

| 层 | 用什么 |
|---|---|
| 数据 | Python 3.13 + sqlite3 |
| 窗口 | pywebview（Windows 上是 WebView2） |
| 界面 | 手写的 HTML / CSS / JS，没有框架 |

## 踩过的坑

记几条，以后回来看：

- **金额校验要守在所有入口。** 一开始只在界面层挡，后来发现函数层也被人绕过去，最后把 `check_money` 抽出来，统一守三处。
- **"跑通了"不等于"对了"。** 最危险的是改了一半 —— `ask_key` 五处只改了两处、`min`/`max` 只改一个，程序照样跑，但行为是错的。**会叫的错是礼物，不会叫的错才是敌人。**
- **数据不能放在程序目录就完事。** 别人的电脑上那个目录没有写权限，所以必须有 `%APPDATA%` 那条分支。
- **透明 ≠ 白。** 本来想写个像素扫描去掉图片白边，后来发现 `cover` 就够了 —— 白写的那套刹车逻辑，整段删掉。
- **别等它变好再发。** 这个 v0.1 的时候只有四张表，很简陋，但它现在是历史的一部分。
